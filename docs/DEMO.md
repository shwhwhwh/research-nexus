# Demo / 使用演示

[Download / watch the MP4](https://github.com/shwhwhwh/research-nexus/releases/download/v0.2.0/research-nexus-demo.mp4)

This is a recording of the real Research Nexus designer using a separate backend, fresh browser profile, and fictional data. The recording captures only that window's web contents. No desktop screen, real third-party application, personal account, library, paper, conversation, or notification is captured. Service credentials are removed from the isolated backend's environment.

The demo temporarily hides built-in service shortcuts and uses fictional node labels. Local artifact locations are displayed as “Local output folder.” These are presentation changes for privacy; the source-to-file plan is generated by a real local agent, tested by RN, enabled, and executed twice. The model's waiting time is cut short in the recording. The second connection is a design example and is not activated.

演示使用真实 RN 设计器，但运行在独立后台、全新浏览器目录和虚构数据环境中。只录制 RN 自身内容，不捕获桌面、真实第三方应用、账号、文献库、研究对话或通知。内置服务快捷入口在演示副本中隐藏，节点使用虚构名称，本地文件位置以通用文字显示。实际调用本地 Agent 生成方案；等待过程已剪短。三条样例经过去重得到两条，真实写入本地 Markdown，再次执行后文件内容保持一致。新增的第二条连线只展示设计方式，未启用。

## Reproduce / 复现录制

After normal setup, install FFmpeg separately and make it available on PATH (or set `RN_DEMO_FFMPEG` to its executable). Log in to a supported local Codex CLI. Then run:

```powershell
.\node_modules\.bin\electron.cmd scripts/record-demo.cjs
```

This invokes your local Codex account on fictional data and may consume model usage. The MP4 and poster are written to `docs/assets/`; isolated runtime files and private QA reports go to ignored `artifacts/`. The MP4 is excluded from source control and is distributed as a release asset. Review the output before publishing. No third-party media or audio is included.

安装依赖后，另行准备 FFmpeg，并登录支持的本地 Codex CLI。运行上述命令会调用该账号并消耗额度。视频与封面输出到 `docs/assets/`，隔离运行数据保存在被忽略的 `artifacts/`。视频通过 Release 发布，不加入源码 Git 历史；发布前须检查画面。
